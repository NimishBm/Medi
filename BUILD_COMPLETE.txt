QUICK START (5 MINUTES)
================================================================================

1. Install Dependencies:
   npm install
   cd server && npm install && cd ..
   cd client && npm install && cd ..

2. Setup MongoDB (choose one):

   Option A - Docker (recommended):
   docker run -d -p 27017:27017 --name mongodb mongo:6.0

   Option B - Local MongoDB:
   brew services start mongodb-community    # macOS
   mongod                                    # Windows/Linux

3. Configure Environment:

   Create server/.env:
   MONGO_URI=mongodb://localhost:27017/clinicflow
   JWT_SECRET=dev_secret_change_in_production
   PORT=5000
   NODE_ENV=development

   Create client/.env.local:
   VITE_API_URL=http://localhost:5000
   VITE_SOCKET_URL=http://localhost:5000

4. Seed Database:
   cd server && npm run seed && cd ..

5. Start Development:
   npm run dev

6. Open Browser:
   http://localhost:5173

REAL-TIME QUEUE SYSTEM
================================================================================

How It Works:

1. Patient Books Appointment
   → Token generated automatically
   → Status: BOOKED

2. Receptionist Checks In Patient
   → Status: CHECKED_IN
   → Queue entry created
   → Status: WAITING
   → Socket.IO broadcasts to all connected clients

3. Doctor Logs In, Views Queue
   → Joins Socket.IO room: queue-{doctorId}
   → Sees all WAITING patients

4. Doctor Calls Next Patient
   → Patient queue status: CALLED
   → Socket.IO broadcasts instantly
   → Patient UI updates without refresh
   → Patient sees "Your Turn! Go to Room 1"

5. Doctor Starts Consultation
   → Status: CONSULTING
   → Timer starts

6. Doctor Completes Consultation
   → Consultation duration calculated
   → Doctor's average consultation time updated
   → Status: COMPLETED
   → Next patient automatically called
   → Process repeats

All updates happen in REAL-TIME via Socket.IO - no page refresh needed!
